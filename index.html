03 / QUICKSTART

Start here.
Build your first workflow.

After installing FlowX, connect your agent with MCP or use the Python SDK directly. You'll need Python 3.10+ and a configured LLM provider.

01 / MCP

Connect your agent

Register the local service in your MCP client. Replace the paths with your virtual environment and configuration directory; on Windows, use the Scripts executable.

mcp.json
{
  "mcpServers": {
    "flowx": {
      "command": "/absolute/path/to/venv/bin/flowx-mcp",
      "env": {
        "FLOWX_CONFIG_ROOT": "/absolute/path/to/config"
      }
    }
  }
}

Set FLOWX_LLM_PROVIDER, FLOWX_LLM_MODEL, FLOWX_LLM_API_KEY, and FLOWX_DEFAULT_WORKSPACE in the configuration directory's .env; never commit secrets to a repository.

02 / PYTHON SDK

Build a workflow in code

Once your LLM is configured, use the SDK to build a workflow from natural language and inspect its artifacts.

build_workflow.py
from flowx_sdk import FlowXClient

with FlowXClient(workspace="./workflows") as flowx:
    result = flowx.build_workflow(
        "Build a workflow that summarizes a document.",
        await_repair_input=False,
    ).raise_for_failure()

    print("Workflow:", result.workflow_id)
    print("Artifacts:", flowx.artifacts(result.workflow_id))

Configure the model variables in the SDK's environment. Building may execute node tests; review the artifacts and code before running the service.

06 / GOOD TO KNOW

Questions.

Want to know more about FlowX?

Read the full documentation ↗
Is FlowX a visual workflow editor?+

No. FlowX is a generative workflow layer and does not include a user interface. Your agent or application handles interaction and presentation; FlowX generates, runs, and evolves the process behind it.

Where are generated workflows stored?+

Workflow artifacts are stored in your configured local workspace, including the workflow graph, node code, and backend entry point. You can inspect and evolve them later.

What happens when a node fails its test?+

Node building includes audit, testing, and bounded repair. You can provide repair guidance when needed; nodes that still fail are not published.

How can I connect to FlowX?+

FlowX supports local stdio MCP, a Python SDK, and an A2A adapter. The A2A adapter currently supports non-streaming workflow building.
